MY PRINCIPLES 3 PRINCIPLES

01. KNOW THE HARDWARE

Software runs faster and more predictably when it is designed around how the CPU, memory, and operating system really work.

02. MEASURE, DON'T GUESS

Do not guess where the slowness is. Use real benchmarks and measurements to decide what to improve.

03. DESIGN BEFORE CODE

Decide how data stays correct and how the system recovers from failure before writing the code.
